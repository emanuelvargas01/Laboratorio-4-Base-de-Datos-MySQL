# Laboratorio #4 Implementación de conexion con Base de Datos MY SQL
**Fecha:** [23/09/2026]

## Contenido del Repositorio
En este programa se realiza un pequeño formulario en el que se pueden registrar multiples productos y estos se almacenan en una base de datos MY SQL. El programa es capaz de añadir, modificar y eliminar productos de la base de datos. En este laboratorio se aprendieron las bases para hacer la conexion a un servidor sql, y poder hacer consultas a la base de datos.

## Tecnologías Utilizadas
* **Lenguaje:** C#
* **Entorno / Framework:** .NET FRAMEWORK
* **IDE / Editor:** Visual Studio 2026
* **Base de Datos: ** My SQL
* **Herramientas:** Git
